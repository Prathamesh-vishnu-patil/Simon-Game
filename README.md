🎮 Simon Says Game

A classic memory game built with HTML5, CSS3, and JavaScript. Test your memory by repeating an ever-growing sequence of light and sound signals!

📌 Features

Interactive Gameplay: Simple, engaging, and progressive level difficulty.

Visual Feedback: Distinct flash indicators for both game prompts and player clicks.

Audio Experience: Dynamic background music, press sounds, and custom game-over sound effects.

Responsive Layout: Centered interface optimized for desktop browser interactions.

🕹️ How to Play

Start the Game: Press any key on your keyboard to begin.

Watch & Remember: The game will flash a random button sound/color to signal the sequence.

Repeat the Sequence: Click the colored buttons in the exact order shown.

Advance Levels: Each correct sequence adds a new step and advances you to the next level.

Game Over: Making a wrong move ends the game, displays your final score, and allows you to restart by pressing any key.

🚀 Getting Started

To run this project locally on your machine, follow these steps:

Prerequisites

A web browser (Google Chrome, Mozilla Firefox, Safari, Edge, etc.)

Installation & Setup

Clone the repository:

git clone https://github.com/your-username/simon-says-game.git


Navigate to the project directory:

cd simon-says-game


Run the Game:
Open simon.html directly in your browser, or use a local server extension (like Live Server in VS Code) for the best experience.
